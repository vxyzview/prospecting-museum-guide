The flat-stat rule (why GUARDIAN mutates first). A mutation multiplies a piece's stat values. Flat stats gain the full ×1.6. % stats don't: a Size Boost of +B% becomes +1.6B%, so output moves by (1 + 1.6B) / (1 + B) — only +28% on a +90% roll, +41% on Clockwork's +210% ceiling, +0% on a rolled zero. My mutation queue: flat-luck pieces, then flat-strength pieces, and %-heavy pieces only after their roll is already fat. Full derivation in my work.

Event calendar around the forge. Rainbow admin events roughly double Prismatic odds (0.56% → 1.8% at one stone; 13% at eight). Candy Canes week lets Festive onto the table. If a Festive or Prismatic Catalyst relic ever drops, it applies directly and beats every roll — bank those.

05Show my work

W1Stat tier grades — what 4×++ means

My own scale for how deeply each stat layers in this game. Grades: 1× ambient, 2× minor, 3×++ strong additive, 4×++ the layers that compound.

Luck, Capacity, Size, Sell, Mod, Dig speed, Shake speed4×++ — they compound and stack multiplicatively at the edges
Dig Strength, Shake Strength, Treasure3×++ — threshold-bound: a Dig Strength point pays once it crosses a toughness gate
W2Expected catalysts per mutation — the arithmetic

For a target with per-roll chance p when loading N stones per roll, the expected stone spend to land it is (1 / p) × N. Against the wiki table that lands at ~40 stones for Gold, ~60 for Diamond, ~100 for Granite or Overclocked, ~185 for Prismatic — remarkably stable across roll sizes (the chance scale mostly tracks the stone count), so loading more stones per roll changes variance, not cost. With a Rainbow event at 8 stones per roll (13%), Prismatic drops to ~61 expected stones, comparable to baseline Diamond farming.

W3Mutation dilution — flat vs % stats

Flat stat: output is the value itself, so ×1.6 is a true +60% (Guardian Pendant 6★ 3,000 → 4,800 luck). Boost stat: output is 1 + B. After the mutation it is 1 + 1.6B. Real gain = (1 + 1.6B) / (1 + B). Worked cases: B = 0.9 gives +28%, B = 2.1 (Clockwork's best) gives +41%, B = 0.3 gives +14%, B = 0 gains nothing. The gain approaches +60% only as B grows — which is why a god-roll % piece mutates well and a fresh one does not. Same logic grades % stat rolls when assigning pieces low dilution first.

W4Event class math — additive vs multiplicative

Take a good desert window: base ×1 plus Sun Blessing (+1×) and smaller additives, say stack = ×6 with Sandstorm counting inside. Hallows' Eve adds +1×: ×6 becomes ×7, a +15% effective boost. Night of the Bonfire or Meteor Shower multiplies: ×6 becomes ×12, a +100% boost, and that ratio holds at stack depth ×3 or ×9 — which is why both true ×2 luck events grade 4×++ regardless of season, and +1× ones stay 3×++.
